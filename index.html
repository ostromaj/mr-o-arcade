PLAYING WITH YOUR CLASS

  • Gate Crash: one person presses Host a game and reads out the 4-letter room code. Everyone else types it in and presses Join.
  • Packet Thief: type the same party code on the title screen to team up (up to 4). Add ?class=yourclass to the link for a class leaderboard.
  • Team Tug: your teacher opens the host screen on the board. Press Join on the Team Tug card, type the 4-letter code and your first name.
  • Your scores and personal bests are saved in your own browser, so use the same computer if you want to beat them.
