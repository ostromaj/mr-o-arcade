# Mr. O's Arcade

One link for all of Mr. Ostroman's review games for IB Computer Science and IB Math Applications & Interpretation.

**Play:** https://ostromaj.github.io/mr-o-arcade/

## Adding a new game

Copy one of the `<a class="card ...">` blocks in `index.html` into the right section, then change the link, topic, title, description and tags. Use `card cs` for Computer Science, `card math` for Math, and `card fun` for the Just for Fun section.
